# Student Management System (C++)

## About Project
This is a beginner-friendly C++ mini project based on file handling. It helps users manage student records.

## Features
- Add Student
- Display All Students
- Search Student by Roll Number
- Save Student Details in a Text File

## Concepts Used
- C++ Programming
- File Handling
- Functions and Loops
- If-Else Statements
- File Input and Output (`ifstream`, `ofstream`)

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the program:
   `g++ student_management.cpp -o student`
4. Run the program:
   `./student`

## Storage
Student records are stored in `students.txt`.
